# Working in Lockness

This is a project-level design repository. Read README.md, docs/design/decisions.md and .specify/memory/constitution.md before proposing changes.

Keep the work at project altitude: architectural contracts, user stories, model design, cross-repository dependencies and outcome evidence. Component implementation belongs in the named implementation repositories. No agent team or production work is authorized by these files.

Run ./tools/check-docs.sh for documentation changes. Update curated speech companions and their source hashes together with pages. Report design, model, implementation, CI and deployment evidence separately.

The existing cardano-utxo-csmt lane was paused during this repository's creation. This repository does not release that pause.
